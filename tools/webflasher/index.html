CrossPad flasher

Flashes the ESP32-S3 and the STM32 straight from the browser — a phone is enough. Needs Chrome (desktop, or Android via WebUSB). No iOS: Safari has neither Web Serial nor WebUSB. Get the firmware files from the release you want and pick them below.

1 · ESP32 — normal update (device is running)

The CrossPad shows up as Crosspad (USB CDC). Sends the app over OTA; the device asks on its screen unless auto-accept is on, then restarts. The assets partition is not part of this — use step 2 when the STM32 image or the icons changed.

2 · ESP32 — recovery (app does not start)

Talks to the ESP32 ROM bootloader through the STM32 bridge (CrossPad MIDI+Serial). Writes every partition you pick; only the app is required. Wipes the OTA selection back to the first slot when ota_data_initial.bin is included.

3 · STM32 — firmware over USB DFU

The STM32 must be in DFU mode: press Enter DFU while the CrossPad is running, or hold pad 1 while plugging the USB cable in. A dead STM32: short SWCLK to 3V3 on the SWD header while plugging in. It enumerates as STM Device in DFU Mode. Page 0 is erased first and written last, like the desktop tool: an interrupted flash lands back in DFU on the next power cycle instead of a brick.
